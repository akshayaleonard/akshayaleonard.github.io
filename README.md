# Akshaya Leonard · MD Portfolio

Live site: https://akshayaleonard.github.io

## Adding an activity each semester
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open **akshayaleonard.github.io** → **Activities** → **Add an entry**.
3. Fill in the title, year, semester, competency, description and (optionally) the Gibbs reflection.
4. Under **Evidence**, add each certificate or photo (Image, plus the PDF if you have one).
5. Click **Save**. The site updates at the same address within a minute or two.

All content lives in `content/` and all uploads in `uploads/`.
